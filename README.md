## Spring Boot React WebSocket Chat

Spring Boot와 React를 기반으로 구현한 실시간 채팅 프로젝트입니다.  
WebSocket를 이용해 클라이언트와 서버 간 양방향 통신을 구현했습니다.

## 기술 스택
- Java 17
- Spring Boot
- Spring Data JPA
- WebSocket
- H2 Databse (개선 예정)
- React
- Vite

## 주요 기능
- WebSocket 기반 실시간 채팅
- 채팅방 입장 및 메시지 송수신
- 채팅 메시지 DB 저장
- 채팅방별 이전 메시지 조회

## 목표
- WebSocket 통신 구조 이해
- 이후 STOMP / Redis 기반 구조로 확장 가능한 프로젝트 설계
